# Jiayi Liu · Daily Life 📒

一个每日日程本风格的个人网站：一天一页，记录日程、待办和心情。

## 功能
- **今日日程**：填入每天的时间安排（开始–结束、备注、颜色），可设置「仅这一天 / 每天 / 工作日 / 每周这一天」重复；可勾选完成，当前时段会高亮「进行中」，并显示现在的时间线。
- **待办清单**：每件事都有截止日期和时间、优先级、标签；自动分组为「已逾期 / 当天截止 / 即将到来 / 当天完成」，并显示倒计时（还剩 / 逾期多久）。
- **今日笔记 + 心情**：自动保存。
- **一周概览**：点击周条快速切换日期，圆点提示当天的日程和截止事项；键盘 ← → 切换日期，T 回到今天。
- **备份 / 恢复**：导出、导入 JSON 文件。

## 使用
纯静态网页，无需安装。直接打开 `index.html`，或在仓库 Settings → Pages 中选择 `main` 分支发布到 GitHub Pages。

> 数据保存在浏览器的 localStorage 中，只存在当前浏览器里。换电脑 / 换浏览器前请先「备份」，再到新设备上「恢复」。
